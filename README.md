## `// 02 :: ABOUT`

I started in ML — models, experiments, feature engineering. What pulled me deeper was everything *around* the model. How does data get there cleanly? How does the model actually run in production without breaking a week later?

That's where I've spent most of my time: **pipelines, warehouses, CI/CD, APIs**. Not just training models but shipping them.

Built a full MLOps system for network threat detection — MongoDB as data lake, automated ETL, XGBoost training with MLflow tracking, FastAPI serving, Dockerized and deployed to AWS EC2 via GitHub Actions. Built a Snowflake warehouse with layered ELT and incremental pipelines. Built an Oracle PL/SQL OLTP system with its own custom unit testing framework.

Also mentored students at Skoolam NGO. Explaining a concept clearly is harder than building it.

## `// 04 :: PROJECTS`

### ▸ [Network Security System — MLOps Pipeline](https://github.com/28Deepakpandey/Network-Security-System-MLOps-Project-with-ETL-)

```
MongoDB Atlas ──► ETL Pipeline ──► XGBoost ──► MLflow
                                      │
                                   FastAPI ──► Docker ──► AWS ECR ──► EC2
                                                              ↑
                                                       GitHub Actions CI/CD
```

`Python` `FastAPI` `Scikit-learn` `Docker` `GitHub Actions` `AWS ECR/EC2` `MLflow` `MongoDB`

Full MLOps lifecycle for phishing / network threat detection. 30-feature URL dataset pushed to MongoDB, flows through automated ingestion → schema validation → ETL → XGBoost training with DagsHub/MLflow tracking → FastAPI `/train` and `/predict` endpoints → Docker image → AWS ECR → auto-deployed to EC2 on every push to main. Custom logging and exception handling across all components.

```
RAW ──► STAGING ──► REPORTING
        (Streams + Tasks + Stored Procedures — incremental ELT)
```

`Snowflake` `SQL` `ELT` `Streams & Tasks` `Data Modeling` `Power BI`

Layered Snowflake architecture with incremental ELT pipelines, fact/dimension data modeling, and Stored Procedure orchestration. Not just a working query — a maintainable system with strong data integrity.

---

### ▸ [Content-Based Recommendation Engine](https://github.com/28Deepakpandey/recommendation-system)

`Python` `TF-IDF` `Cosine Similarity` `NLP` `Streamlit`

Movie recommendation on TMDB 5000. TF-IDF vectorization + cosine similarity. Full preprocessing notebook, serialized artifacts (`similarity.pkl`, `movie_dict.pkl`), Streamlit app for live inference.

---

### ▸ [Student Performance Prediction](https://github.com/28Deepakpandey/Student-Academic-Performance-Prediction-System-ML-Project-)

`Python` `Scikit-learn` `EDA` `Supervised Learning`

End-to-end supervised ML pipeline for predicting academic outcomes — data cleaning, EDA, feature engineering, model evaluation.

---

### ▸ [Bank Account Management System (OLTP)](https://github.com/28Deepakpandey/PL_SQL-LAB/tree/main/BankAccountManagementSystem)

`Oracle SQL` `PL/SQL` `Stored Procedures` `Triggers` `Unit Testing`

OLTP schema in Oracle PL/SQL with stored procedures, triggers, and ACID-compliant transaction logic. Built a custom unit testing framework (utPLSQL-style) — structured PASS/FAIL reporting for all database logic.
